# Web Aplication For Reporting Computer Network Speed (Emulator by Eve.ng)

เว็บแอปพลิเคชันรายงานความเร็วเครือข่ายอินเทอร์เน็ต (Web Aplication For Reporting Computer Network Speed)

## รายละเอียดโครงงาน

โครงงานนี้พัฒนาขึ้นเพื่อจัดทำเว็บแอปพลิเคชันสำหรับติดตามสถานะอุปกรณ์เครือข่ายและรายงานค่าความเร็วเครือข่าย (Throughput) ผ่านหน้า Dashboard โดยเชื่อมต่อกับอุปกรณ์เครือข่ายจำลองอาคาร4ชั้นใน EVE-NG ระบบสามารถตรวจสอบสถานะอุปกรณ์ จัดเก็บข้อมูล และแสดงผลข้อมูลเพื่อช่วยในการติดตามและวิเคราะห์การทำงานของเครือข่ายเบื้องต้น

## วัตถุประสงค์

- เพื่อพัฒนาเว็บแอปพลิเคชันสำหรับรายงานความเร็วเครือข่ายอินเทอร์เน็ต
- เพื่อแสดงสถานะอุปกรณ์เครือข่ายผ่านหน้า Dashboard
- เพื่อจัดเก็บและเรียกดูข้อมูล Throughput และข้อมูลที่เกี่ยวข้องกับอุปกรณ์เครือข่าย
- เพื่อประยุกต์ใช้เครื่องมือจำลองเครือข่ายในการทดสอบและติดตามการทำงานของระบบ

## เทคโนโลยีและเครื่องมือที่ใช้

### 1. Web Application Development
- Python
- Flask — Web Framework
- Netmiko — เชื่อมต่อและจัดการอุปกรณ์เครือข่ายผ่าน SSH
- HTML, CSS และ JavaScript — พัฒนาส่วนติดต่อผู้ใช้งาน
- MySQL — ระบบจัดการฐานข้อมูล

### 2. Virtualization and Operating System
- VMware Workstation — ซอฟต์แวร์สำหรับสร้างและจัดการ Virtual Machine
- Ubuntu Server 22.04 LTS — ระบบปฏิบัติการสำหรับรันเว็บแอปพลิเคชันและบริการที่เกี่ยวข้องภายใน Virtual Machine

### 3. Network Simulation and Testing
- EVE-NG — แพลตฟอร์มจำลองเครือข่าย
- Cisco IOSv — Router Image สำหรับจำลองอุปกรณ์เราเตอร์
- Cisco IOSvL2 — Layer 2 Switch Image สำหรับจำลองอุปกรณ์สวิตช์
- iperf3 — เครื่องมือทดสอบและวัด Throughput ของเครือข่าย

### 4. Remote Access and Administration
- PuTTY — เครื่องมือเชื่อมต่ออุปกรณ์ผ่าน SSH
- Bitvise SSH Client — เครื่องมือเชื่อมต่อและจัดการระบบผ่าน SSH

## ความสามารถของระบบ

- เชื่อมต่อและตรวจสอบอุปกรณ์เครือข่ายจำลองใน EVE-NG
- แสดงแดชบอร์ดและกราฟความเร็วThroughputสำหรับติดตามสถานะข้อมูลอุปกรณ์เครือข่าย
- แสดงข้อมูลค่า Throughput ที่ได้จากการทดสอบเครือข่ายแบบทุกๆ1นาที
- ตรวจสอบและแสดงสถานะอุปกรณ์เครือข่ายแบบ topology
- สามารถแสดงพอร์ตinterfaceสถานะการทำงานของอุปกรณ์เครื่องข่าย
- สามารถเพิ่มลบข้อมูลอุปกรณ์และหมวดหมู่อุปกรณ์เบื้องต้นและบันทึกลงฐานข้อมูล
- สามารถแสดงประวัติการทำงานของระบบ Activity Log

## วิธีติดตั้งและใช้งาน

1. เตรียมสภาพแวดล้อม Ubuntu Server 22.04 LTS ภายใน Virtual Machine
2. ติดตั้ง Python, MySQL และไลบรารีที่จำเป็นสำหรับโปรเจกต์
3. ตั้งค่าฐานข้อมูลและข้อมูลการเชื่อมต่อให้ตรงกับสภาพแวดล้อมที่ใช้งาน
4. เตรียม EVE-NG และกำหนดค่าอุปกรณ์เครือข่ายที่จำเป็น
5. ติดตั้งและตั้งค่า iperf3 สำหรับการทดสอบ Throughput ตามโครงสร้างเครือข่าย
6. เริ่มต้น Flask Application และเปิดเว็บแอปพลิเคชันผ่านเบราว์เซอร์
